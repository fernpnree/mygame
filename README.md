# เพื่อนขนฟู ผจญภัย

เกมเลี้ยงสัตว์แนว Idle / Simulation สำหรับเล่นบนมือถือผ่าน browser
เลี้ยงเพื่อนขนฟู จัดทีม 1-3 ตัวส่งไปสำรวจ หาเหรียญ แล้วพาเพื่อนใหม่กลับบ้าน
ปิดเกมไปแล้วเกมยังเดินต่อ กลับมาเปิดใหม่ก็ได้รางวัลที่สะสมไว้

## วิธีเล่นโดยย่อ

- **สำรวจ**: เลือกพื้นที่ จัดทีม แล้วรอเวลา (1 นาที ถึง 1 ชม.) กลับมากด "รับของที่ได้มา"
- **พลังงาน**: การสำรวจใช้พลังงาน พักที่บ้านแล้วฟื้นเอง หรือให้อาหารเพื่อเติมทันที
- **ความสุข**: ลดลงทุกครั้งที่ออกสำรวจ ถ้าเศร้า (ต่ำกว่า 30) จะได้รางวัลน้อยลง ร่าเริง (70 ขึ้นไป) ได้รางวัลเพิ่ม
- **เลเวล**: เพื่อนได้ EXP จากการสำรวจ เลเวลสูงหาเหรียญได้มากขึ้น และปลดล็อกพื้นที่ยากได้
- **กระปุกออมสิน**: เพื่อนที่อยู่บ้านและไม่เศร้าหยอดเหรียญให้เรื่อยๆ สะสมได้สูงสุด 8 ชม.
- **ภารกิจรายวัน** 3 ข้อ (สุ่มใหม่ทุกเที่ยงคืน) และ **ความสำเร็จ** 13 ข้อ
- **สมุดสัตว์**: สะสมเพื่อนให้ครบ 8 ตัว

## เปิดเล่นในเครื่องตัวเอง

ต้องเปิดผ่าน web server (ดับเบิลคลิกไฟล์ `index.html` ตรงๆ จะไม่ทำงาน)

```bash
npm start
```

แล้วเปิด http://localhost:8080

- **โหมดทดสอบ**: เปิด http://localhost:8080/?debug จะมีปุ่มเลื่อนเวลาไปข้างหน้า และปุ่มเพิ่มเหรียญ
- **รันชุดทดสอบสูตรคำนวณ**: `npm test`

## ปรับสมดุลเกม

ตัวเลขทั้งหมดอยู่ในโฟลเดอร์ `js/data/`

| ไฟล์ | ใช้ปรับอะไร |
|---|---|
| `balance.js` | พลังงาน ความสุข เลเวล กระปุกออมสิน ที่นอน ประตู |
| `areas.js` | พื้นที่สำรวจ: เวลา พลังงานที่ใช้ รางวัล ราคาปลดล็อก |
| `animals.js` | ชื่อและนิสัยของสัตว์ พื้นที่ที่เจอได้ |
| `items.js` | อาหาร: ราคา และพลังงาน/ความสุขที่ได้ |
| `missions.js` | ภารกิจรายวันและความสำเร็จ |

## เผยแพร่บน GitHub Pages (เมื่อพร้อม)

1. รวมโค้ดเข้า branch `main`
2. ไปที่ GitHub repo > **Settings** > **Pages**
3. Source เลือก **Deploy from a branch** > branch `main` โฟลเดอร์ `/ (root)` > Save
4. รอสักครู่ จะได้ลิงก์ `https://fernpnree.github.io/mygame/`

ทุกครั้งที่อัปเดตเกม ให้เปลี่ยนเลข `VERSION` ใน `sw.js` เพื่อให้มือถือผู้เล่นโหลดเวอร์ชันใหม่

## โครงสร้างไฟล์

```
index.html              หน้าเกม
css/style.css           หน้าตาทั้งหมด (ธีมพาสเทล)
js/main.js              ตัวควบคุมหลัก: สลับหน้า เซฟ เดินเวลา
js/state.js             โครงสร้างเซฟ / โหลด / อัปเกรดเซฟเก่า
js/data/                ข้อมูลเกมและตัวเลขสมดุล
js/logic/               สูตรคำนวณ (สำรวจ ดูแล ภารกิจ ร้านค้า เวลา)
js/ui/                  หน้าจอแต่ละหน้า
js/art/                 ภาพสัตว์ ไอคอน และฉาก (วาดด้วย SVG)
js/audio.js             เสียงเอฟเฟกต์ (สังเคราะห์ด้วย Web Audio)
sw.js, manifest.webmanifest, icons/   ให้กด Add to Home Screen และเล่น offline ได้
tests/                  ชุดทดสอบสูตรคำนวณ (node --test)
tools/make-icons.mjs    สร้างไอคอนแอปใหม่จากภาพแมว
```
